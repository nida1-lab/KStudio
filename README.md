# KStudio

スマホ向けAndroid開発環境。

## 現在の機能

- Kotlinコードエディタ
- 行番号表示
- シンタックスハイライト
- ワード検索
- 行ジャンプ
- 括弧・引用符の自動補完
- 閉じ括弧の二重入力スキップ
- ペア削除
- Tabで4スペース入力
- Enter時の簡易インデント
- Undo / Redo
- システムのライト / ダークモード対応
- Androidのファイル選択UIを使ったプロジェクトフォルダ選択
- ファイルの開く / 保存 / 新規作成
- フォルダの作成 / 移動
- ファイル・フォルダの名前変更 / 削除
- ファイル内容のコピー
- クリップボード内容でファイルを丸ごと置換
- 最近開いたプロジェクトの記憶
- HOMEダッシュボード
  - プロジェクト
  - 履歴
  - コミュニティ
  - クラウド使用量表示
- プロジェクト一覧
  - 最終編集時間
  - 編集者
  - クラウドバックアップ状態
- 1つ前へ戻るカスタム戻る操作
- 編集中の未保存変更に対するカスタム警告
- 標準AlertDialog / Toastを使わないKStudio独自UI
- Androidアニメーションを使わないUI
- コミュニティ
  - #タグ
  - #検索
  - ワード検索
  - スレッド
  - 登録アカウント名での投稿
  - @メンション入力候補
  - @ / #の強調表示
- 共同コーディング基盤
  - 所有者 / 準所有者 / 編集者
  - 所有者・準所有者だけのメンバー管理
  - 所有者のみプロジェクト削除
  - 1ファイル1編集者のロック基盤
  - ロックの定期更新と期限切れ処理
- Preview画面とフルスクリーン表示
- GitHub ActionsによるDebug APKビルド

## 共同コーディングについて

現在はクライアント側の権限UI・メンバー管理・ファイルロック基盤を実装しています。

AさんとBさんが別端末から同じプロジェクトをリアルタイムで共同編集するには、Cloud側の共有データベースと同期APIが必要です。
この接続先は今後のCloud機能実装で追加します。

## Runについて

現在のRunは、KStudioアプリ内での基本的な静的チェックです。
実際のAndroid APKビルドはGitHub Actionsで行います。

## ビルド

GitHub Actionsの「Build APK」を手動実行するか、mainへのpush / pull requestでビルドできます。
Debug APKはActionsのArtifactとして取得できます。
